为什么做 ThreeFingerMiddle？

我很喜欢 Windows 上三指轻触触控板来模拟鼠标中键点击的功能——关闭浏览器标签页、打开链接到新标签页都非常方便。切换到 macOS 后，这个便利的手势却消失了。

于是，ThreeFingerMiddle 诞生了。它将这个好用的手势带到 macOS 触控板：三指轻点即可触发中键点击。轻量、本地运行，开箱即用。

功能特点

  • ✨ 简单直观：三指轻点触控板，自动模拟中键点击
  • 🪶 轻量高效：纯本地运行，不占用系统资源
  • 🔒 隐私安全：不联网，不收集任何数据
  • 🎯 精准定位：在当前光标位置触发中键事件
  • 🚀 开箱即用：安装后即可使用，无需复杂配置

如何安装？

系统要求：macOS 13.0 或更高版本

  • 1. 点击下方按钮下载 DMG 安装包
  • 2. 双击打开 DMG 文件
  • 3. 将 ThreeFingerMiddle 拖入「应用程序」文件夹
  • 4. 首次运行时，系统会要求授予「辅助功能」权限
  • 5. 前往「系统偏好设置 → 隐私与安全性 → 辅助功能」，勾选 ThreeFingerMiddle
  • 6. 完成！现在你可以使用三指轻点来触发中键点击了

Why ThreeFingerMiddle?

I loved Windows' three-finger light tap that simulates a middle mouse click—so handy for closing browser tabs, opening links in new tabs. When I switched to macOS, I missed that convenient gesture.

So ThreeFingerMiddle was born. It brings that useful gesture to the macOS trackpad: three-finger tap triggers a middle click. Lightweight, local, ready to use.

Features

  • ✨ Simple & Intuitive: Three-finger tap to simulate middle click
  • 🪶 Lightweight: Runs locally with minimal system resources
  • 🔒 Privacy & Security: No network access, no data collection
  • 🎯 Precise: Triggers middle click at current cursor position
  • 🚀 Ready to Use: Works right after installation

How to Install?

System Requirements: macOS 13.0 or later

  • 1. Click the button below to download the DMG installer
  • 2. Double-click to open the DMG file
  • 3. Drag ThreeFingerMiddle to your Applications folder
  • 4. On first launch, the system will request Accessibility permission
  • 5. Go to System Preferences → Privacy & Security → Accessibility, and enable ThreeFingerMiddle
  • 6. Done! Now you can use three-finger tap to trigger middle clicks
