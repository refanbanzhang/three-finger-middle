# ThreeFingerMiddle

A tiny local macOS app that does one thing:

- three-finger tap on the trackpad
- emits a middle mouse click at the current cursor position

## Build

```bash
./build.sh
```

## Package DMG

```bash
./package-dmg.sh
```

## Run

```bash
open build/ThreeFingerMiddle.app
```

The first launch may ask for Accessibility permission.
